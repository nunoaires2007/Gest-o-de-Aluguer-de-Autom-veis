# Gest-o-de-Aluguer-de-Autom-veis
Projeto em Haskell para desenvolver um Sistema de Gestão de Aluguer de Automóveis, permitindo gerir clientes, veículos e alugueres, consultar históricos, verificar disponibilidades e calcular custos.


# Estrutura

src/
├── Model.hs
├── Domain.hs
├── Dados.hs
├── Validacao.hs
└── Relatorios.hs

app/
└── Main.hs

test/
└── Testes.hs

data/
└── alugueres.txt
